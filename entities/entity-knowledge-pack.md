A proposed Claude Code skill and its output artifact: a git-backed collection of atomic, typed knowledge nodes (Decisions, Facts, Entities, Artifacts) extracted turn-by-turn from long, multi-media Claude sessions, structured as a context graph so the knowledge is reusable by other Claude sessions or teammates without re-reading the original transcript.
